# Native dependency inventory

October 20, 2026. [Cargo inventory](verification/rust-dependencies.json) records the exact resolved workspace graph, licenses reported by package metadata, repositories and sources. [Cargo.lock](../Cargo.lock) pins registry package versions/checksums. The inventory includes target-conditional packages, not only code linked on this Mac.

Selected dependencies are egui/eframe 0.37.0, wgpu 30.0.1, serde 1.0.229, serde_json 1.0.151 with arbitrary precision, rusqlite 0.40.2 with bundled SQLite and its native backup API, sha2 0.10.9, uuid 1.28.0 and direct getrandom 0.4.3 for private-launch OS entropy. Native audio adds CPAL 0.18.2 (default features disabled) and rtrb 0.4.0; ASIO is disabled. Consistent sealed take export uses SQLite backup rather than copying a potentially live database file. The backup feature adds no new registry package. The getrandom version was already in the locked dependency graph. The session service uses existing workspace dependencies and bounded standard-library channels; it adds no registry packages. Source/license discussions and primary links are in the [UI](research/RUST-UI.md), [audio/MIDI/plugins](research/RUST-AUDIO-MIDI-PLUGINS.md) and [models](research/RUST-MODELS.md) investigations.

The resolved graph currently has 399 packages, including seven local OmniuSong crates (core, store, app, recording, IPC, session service and engine), and one patched third-party package as a local path dependency. Those local packages have no distribution license selected yet. Do not infer one from dependency licenses. Before shipping, generate retained third-party notices for the actual packaged target/features, including bundled fonts and native libraries, and make the application's distribution decision explicit. Model weights, voicebanks and plugin SDKs have independent terms and must enter this inventory when actually selected/linked/bundled.

The initial Mac development bundle is ARM64 and ad-hoc signed with the stable identity `local.omniusong.native-preview`. It is a locally reviewable development build, not a notarized production installer or a proof of another Mac/Windows target. The examined dynamic links are Apple system frameworks/libraries; no Node/Python runtime or local service is linked or started by the native shell. Installed cold-start, updates/uninstall, complete notices, signing/notarization and actual Windows acceptance remain release work.

Recreate metadata with `cargo metadata --format-version 1 --locked`. Changes in target features/dependencies require a refreshed inventory and license review. No gated model/voice terms, paid SDK agreement, distribution account or signing identity was accepted during this baseline.

## Pinned native input patch

The audio graph adds twelve registry packages and one OmniuSong workspace crate. The selected CoreAudio wrapper, `coreaudio-rs` 0.14.2, is retained under `vendor/coreaudio-rs` with both original license files and [exact upstream provenance](../vendor/coreaudio-rs/UPSTREAM.json). The root Cargo patch table selects that reviewed local source. Its [patch notes](../vendor/coreaudio-rs/OMNIUSONG-PATCH.md) describe fixed input-buffer ownership/preallocation, a 16,384-frame setup ceiling and a zero-frame/zero-byte unknown-loss sentinel. These address source-level callback allocation and allocation-layout issues found during independent review. They do not establish general native-driver or exceptional CPAL error-path realtime safety.

The prior [386-package inventory](verification/rust-dependencies-pre-audio.json) remains a historical snapshot. The vendor test lock is separate from the production root lock; its tests do not open devices. CPAL/native input, loopback, listening, latency and Windows acceptance remain separate from dependency compilation.
