## Resolved review findings

- Cold recovery originally depended on normal startup, whose creation policy can recreate an absent studio. The explicit `--evidence-history` mode now starts an unopened existing-only worker and opens history without Initialize. A real worker/headless regression keeps the missing original root absent across five frames. Normal startup remains outside that recovery guarantee.
- Every request and terminal payload must match its exact current offered action, serial, epoch, generation, path/job identity and request fingerprint. Incorrect payloads retain credit; correct late results become historical evidence.
- Dispatch rechecks the complete musical/audio/retry context, including changes while the evidence window is closed and before another paint. New jobs cannot save or discard an unrelated draft or continue into audio.
- Accepted Inspect, Read and Reconcile retire previous current proof immediately. Failed reads preserve only historical evidence. A repeated destination or A-to-B-to-A field change cannot revive a confirmation.
- Cancellation checks the exact model pending ID as well as the session request and retains both credits. EOF records uncertainty without generic retry. Positive composition and EOF coordinator regressions now supplement the pure model cases.
- Primary outcome, later governor stop, metadata-persistence failure and current catalog retirement are independent. A nested retirement invalidates the generation while preserving a newer unsaved draft and exact retained musical retry. Historical successes explicitly imply no new execution or current artifact check.
- Canonical Library origin survives reconnect. Explicit metadata connection replacement sends no Initialize. Successful explicit initialization clears only the stale Initialize retry; musical retries remain retained.
- Pending cancellation is outside scrolling detail. Reply validation bounds data before cloning/retention, and narrow/light/dark headless checks cover independent error text. Three native path inputs have explicit accessible names.
