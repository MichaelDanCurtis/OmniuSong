## Findings corrected before the final gate

1. **Validation race:** typed history/operation uniqueness was initially checked before the store write transaction. Different writers could validate the same old history and publish mutually conflicting choices. The typed service now uses an exact whole-history fence inside IMMEDIATE, before replay and writes. A stale preimage returns a known no-write conflict; explicit retry loads and validates fresh history. The opaque store also authenticates and compares the entire expected postimage. Tests cover unrelated/concurrent changes, replay, different action identities, duplicate operation refusal and unsupported later histories.
2. **Impossible retained-review shapes:** Prepared metadata now requires the supported file/usage ceilings, conservative unknown tail and a positive selected checkpoint. Existing checkpoint/Finish codec validation is reused, with initial worker/session/Panic scope relationships added. Independently rehashed malformed fixtures distinguish request-shape validation from a bad digest. These checks never authenticate the present filesystem source.
3. **False mutation uncertainty:** known pre-write malformed/hash/root/origin/immutable-choice refusals map to the existing metadata `IntentRejected` classification before the generic mutating-command wrapper. Metadata identity validation does not borrow the source reader's `SourceUnavailable` classification. Real database errors, fatal catalog handling and possible writes retain their conservative failure semantics.

No remaining concrete blocker was identified for this backend-only Prepared ledger after those corrections. Typed actions are immutable canonical version-1 requests with no success or execution phase. Exact raw review bytes, the prior domain-separated review identity and the stable source-admission projection remain distinct. A stored optional historical request link proves that exact request relationship, without manufacturing Finish or source success. Unlinked means unlinked, not proven orphanhood.
