# Initial independent native protocol review

October 20, 2026. Read-only review of `crates/omniusong-core/src/contracts.rs` and `docs/contracts/NATIVE-PROTOCOLS.md` against the native migration goal and recording milestone.

**Bounded result: no concrete major protocol/ABI correctness finding.** The reviewed definitions are suitable as the declared boundary for the next implementation stage. This is not approval of an implemented engine, IPC transport, recorder, plugin host or model worker; those components and their enforcement remain separate gates.

| Area | Review conclusion |
| --- | --- |
| Version, size and metadata | `Envelope::decode` checks the channel ceiling before deserialization, then exact version/protocol, payload and extension validation. Encoding rechecks serialized size. Declared extension points preserve unfamiliar numbers, with depth/count/string bounds and reserved-field rejection. Inner semantic layouts are strict. The framing receiver must still reject lengths before allocating; this module does not implement that receiver. |
| Clocks and capture | Signed audio timeline frames remain distinct from unsigned source offsets and host ticks. Alignment checks domain/host epoch and audio epoch/rate; bounded rational conversion uses `i128` and checks the final timeline range. Raw UMP count/group/channel checks and measured-expression event provenance are present. Quarantined packets cannot directly drive musical events. These checks are not a complete MIDI decoder or proof of calibrated device timing. |
| Cancellation and acceptance | `Cancelling → Succeeded` is forbidden; terminal job/candidate states cannot resume. A result contains objects/proposal and does not commit the project. Both acceptance request forms are explicitly routed through one main-store transaction and operation ledger. The supervisor still needs to serialize result/cancel admission, compare results with their admitted request, enforce grants/budgets and retain idempotent durable outcomes. These are declared policies, not protections supplied by a stateless envelope. |
| Realtime and ABI | `RealtimeBatch`/`RealtimeControl` contain fixed `Copy` data, numeric handles and no owned heap/refcount destructors. Batch construction/push checks epoch handle, block overflow/size, offsets, order, values and capacity before mutation. They are explicitly process-local Rust types. The document requires a separate versioned byte-layout codec for cross-process plugin slots; directly sharing Rust enum memory would violate this contract. No current code claims that codec exists. |
| Native recording | The design separates writer-owned per-take journals from project transactions, hashes interpretation headers with immutable chunks, advances a committed prefix atomically, and emits receipts after commit. Sealing precedes project publication, leaving recoverable orphaned takes on interruption. Recovery, gaps, archive traversal and retention roots are explicit, and schema-1 whole-file limits are not reused as long-recording limits. Exact chunk/manifest codecs, schema and fault-tested writer implementation remain required. |

Before milestone 2 acceptance, preserve the stated implementation gates: authenticated private framing plus sequence/session replay checks; nonblocking queues and prepared-resource retirement; exact slot/chunk codecs and ownership ordering; independent MIDI/parser fixtures; operation-ledger/cancel-result race tests; and recording kill/stall/disk-full/overflow/finalization tests. `Validate`, `Copy`, a nonce field or a successful JSON round trip alone proves none of those runtime properties.

The eight contract tests were read. Their checks include flattened arbitrary-precision wire numbers, wrong version/channel/size, clock/address constraints, fixed-batch limits, handshake/result round trips, terminal transitions, MIDI-only commit receipts and the cancellation record. The coordinator reported those eight passing. No competing Cargo command or new test execution was run for this read-only pass. The final workspace gate, native device behavior, lock freedom, physical latency, listening, plugin crashes, actual inference and thirty-minute capture remain outside this review's evidence.
